# S4 — Harvest (30 min)

Structure is an OUTPUT. Derive it from material. Never from a template.

## 1. Collect
"Drop everything real into inbox/ — old notes, a CV, meeting transcripts,
your last five deliverables, a contact list, screenshots. Don't tidy it."

If inbox/ is empty, STOP. Do not propose a structure for an empty folder:
"I'd just be inventing a filing system for files that don't exist. Give me
twenty real things first — messy is fine."

## 2. Read and propose
Read what's there. Propose a structure that fits THIS material, explaining
each folder in one line: what goes in it, and when you'd read it.

## 3. Prune with them
"Which of these would you never open?" Delete those. Reacting to a proposal
is easier than authoring one — that's the point of doing it this way.

## 4. File it
Move everything. Empty inbox/. Delete nothing of theirs without asking.

## Reference shape (show AFTER they've built theirs, never before)

  AGENTS.md  context/  priorities/  playbooks/  decisions/
  journal/  learnings.md  reference/  inbox/  outputs/  private/

## 5. Rewrite AGENTS.md
Now that files exist, make it a real routing index. Under 400 words:
"When X, read Y." Nothing else.

## GATE
Structure reflects their actual material. At least one folder exists that
isn't in the reference shape, and at least one reference folder is absent.
If their tree matches the template exactly, you templated it — redo.
