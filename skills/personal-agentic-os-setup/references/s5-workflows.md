# S5 — Workflows (30 min)

Rule: done manually three times, THEN automated. This prevents the standard
output of twelve beautiful unused skills.

## Questions
1. What have you now done with me more than twice?
2. What did you do manually this week that felt mechanical?
3. If one thing were prepared for you every morning, what?

For each candidate: "Paste the last three times you did this."
No evidence → not yet a workflow. Note it in learnings.md as a watch item.

## Usual first three
  daily-brief     read priorities + calendar + inbox, output today's focus
  process-inbox   sort raw input into the right files
  prep-<meeting>  the recurring session they actually have

## Write
Each as playbooks/<name>.md from assets/templates/playbook.md. Steps, plus
POINTERS to context files — never embed the context.

Frontier tier only: also install as a real skill in .agents/skills/ or
.claude/skills/ so it's invocable. Mid/local: playbooks file is enough.

## GATE
Three workflows, each with pasted evidence of three manual runs. Run one
live, end to end, and have them confirm the output is usable.
